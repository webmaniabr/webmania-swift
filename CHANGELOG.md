# Changelog

## Unreleased

- README rewritten for integrators: requirements, installation, credentials from environment variables, homologation examples that issue, consult and cancel an NF-e and an NFS-e, and the method list per product. The technical details that were in the README moved unchanged to `docs/INTEGRATION.md`, `docs/TESTING.md`, `docs/OPERATIONS.md` and `examples/homologacao/README.md`. Documentation only.
- README: the SDK is presented as available from the public GitHub repository and installed from a clone (`git clone https://github.com/webmaniabr/webmania-swift.git`); it is still not published to a package registry. Documentation only: code and contract are unchanged.
- Homologation example: `WEBMANIA_LIVE_ALLOWED_HOSTS` is required (exit 77 before any credential or request when it is missing or empty), and the top-level payload `ambiente` must be exactly the JSON integer 2 (the text `"2"`, `2.0` and `2e0` are refused).
- Homologation example: after an NFS-e cancellation the example keeps consulting while the document is in `processando_cancelamento`; only `cancelado` counts as success. `scripts/qualify.py` now builds the example and checks offline that each of its guards exits with 77 before any request (`scripts/check_example.py`).
- Contracts regenerated from the current public OpenAPI: tax-class list items (`nfeListTaxClasses`) are read with dedicated schemas that accept every value a saved class returns (ICMS `nao_contribuinte` as a boolean or `"0"`/`"1"`, a `null` rate when none is stored, one object instead of a list for NFCom and NFS-e groups, `type` always present); the tax-class save request (`nfeSaveTaxClasses`) follows the rules the save enforces (per-UF ICMS rates are `{estado, aliquota}` instead of `{estado, valor}`, `icms`, `ipi`, `pis` and `cofins` need at least one scenario, IBS/CBS `credito_presumido` is one object, `aliquota_carga_efetiva` is no longer published).
- Contracts regenerated from the current public OpenAPI: tax-class list totals (`tributos_federais`, `tributos_estaduais`) accept an empty string for an unset value; tax-class `situacao_tributaria` has 2 digits for IPI, PIS and COFINS and 2 to 3 for ICMS; NFS-e `impostos.reducao` and `impostos.cp` accept text or a JSON number.
- Homologation example: the issued document is consulted until a terminal status and cancelled once a consult shows `aprovado`, whether the issue call approved it or it was approved later (before, a document approved after the issue call was left uncancelled); a refused document gets no other mutation, and one without a terminal status within the bound is ledgered as `unknown` (never resent); the refused NF-e status is `reprovado`. The lifecycle runs through injected steps, and `examples/homologacao/Tests` drives it offline (approval after the issue, `processando_cancelamento` then `cancelado`, refused, no terminal status, unknown cancellation); `scripts/check_example.py` runs these tests after the guard cases.
- Contracts regenerated from the current public OpenAPI (14 modules, 103 operations, 102 enabled), pinned by `contract_digest` and per-module SHA-256 instead of a commit; internal reconciliation metadata is no longer embedded. Request-body models of the API 2.0 issuance operations are named after their operations (`<OperationId>Payload`).
- New `fiscalDownloadReportV2` and `fiscalReportDownload(url:)`, which downloads a completed report URL only from the configured API2 origin and `/relatorios/` prefix and never follows redirects.
- Legacy `fiscalDownloadReport` accepts CSV and XLSX labeled `text/xml`, identified by the bytes (`Download.format`); XML, HTML and JSON bodies are refused and no other operation gains the tolerance.
- Declared `format: date` request fields (for example CT-e `aereo.previsao_entrega`) must be a `Y-m-d` calendar date before sending.
- `RecoveryReference.consultationParameters()` refuses references of `emitter*` operations; `revealSelector()` remains available for the consultation of that family.
- Each chunk-size line is bounded on its own, independently of the header budget.
- `nfeDownloadIbsCbsEventXml` is not available in this release.
- New optional homologation example in `examples/homologacao`.
